Simpler.Grants.gov · iOS design templates

Ask first, then search, then apply.

The home screen is a plain-language question, following america.gov. Answers come only from Grants.gov listings and cite them. Search, opportunity detail, and the full application flow sit behind it in four tabs: Ask, Search, Apply, Profile.

Assumptions to confirm
• I couldn't access america.gov or the forked repo, so the style here is my own reading of america.gov from press coverage: calm, editorial, one big question box.
• Copy on onboarding, sign-in and roadmap is taken from simpler.grants.gov. Opportunity data is realistic sample data, not live.
• Applicants are the primary user. Grantor (agency staff) entry exists via PIV/CAC sign-in only; grantor tools aren't designed.
• Light mode only, iPhone 15/16 size (390×844).

Paths to try
Ask. Sign in with Login.gov → type a question or tap a suggestion → tap a cited listing.
Search. Search tab → a recent search → toggle Open / Closing soon / Forecasted → Filters sheet.
Apply. Opportunity → Start application → SF-424 (clear the email to see validation) → finish every form → certify → Submit.
Feedback. Profile → Roadmap & feedback → vote, send a note.
